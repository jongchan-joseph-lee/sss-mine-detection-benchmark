Active sonar portfolio · Chapter B

측면주사 소나 기뢰 탐지

AUV에 탑재된 측면주사 소나(side-scan sonar) 영상에서 기뢰 유사물체(MILCO)를 찾는 공개 데이터셋을 다뤘습니다. 데이터를 먼저 진단하고, 영상 신호처리로 표적의 음향 특징을 확인한 뒤, 레퍼런스 AI 모델을 실제 운용 조건(학습에 없던 연도)에서 평가했습니다.

B2

신호처리 image-domain signal processing

이 데이터는 원시 신호가 아니라 이미 영상으로 만들어진 상태입니다. 그래서 신호처리는 영상을 다시 "세기 지도"로 되돌리고, 측면주사 소나의 물리(하이라이트와 그림자)를 확인하는 데 집중했습니다.

1색상표 제거구리색 의사색상 → 휘도. RGB 분산의 94%가 한 축에 있어 단일 스칼라로 복원됩니다.
2축척 통일416 px 영상을 1024 px로 올려 모든 표적을 같은 픽셀 축척에 둡니다.
3수주 구간 검출가운데의 어두운 수직 띠(물기둥, nadir)를 찾아 좌현·우현을 나눕니다.
4횡방향 이득 정규화열별 중앙값으로 나눠 거리·빔 패턴에 따른 밝기 변화를 평탄화합니다.
5스페클 억제3×3 중앙값 필터로 반점 잡음을 줄입니다.
부류표본하이라이트 > +3 dB그림자 < −3 dB
신호처리가 알려준 것. 하이라이트와 그림자는 물체와 해저 배경을 가르는 강한 근거입니다. 하지만 기뢰 유사물체(MILCO)와 비기뢰 물체(NOMBO)는 거의 같은 비율로 같은 신호를 보입니다. 둘을 가르려면 모양·크기·질감 같은 다른 정보가 필요하며, 이것이 AI에 기대하는 몫입니다.
B3

AI 적용 reference models under operational split

두 과제를 공식 연도 분할로 평가했습니다. 학습은 2015·2017·2021년, 시험은 2010·2018년(operational)입니다. 시험 연도의 해역·장비 설정·해저 상태는 학습에 한 번도 나오지 않습니다.

과제 1. 전체 화면에서 표적 찾기 detection

YOLOv8n을 썼습니다. CPU만으로 학습하려고 320 px 타일(표적 중심 + 배경)로 학습하고, 탐지는 1024 px 전체 화면에서 했습니다. B2의 고전적 정합필터 탐지기(하이라이트 뒤에 그림자)와 같은 기준으로 비교합니다. 기준은 표적 중심에서 상자 크기 이내의 점을 맞춘 것으로 보고, 화면당 오경보 수에 따른 재현율(FROC)입니다.

과제 2. 표적 패치 분류 MILCO / NOMBO / 배경

레퍼런스 연구(Mine-JEPA, 2026)와 같은 3분류 과제입니다. 세 모델을 비교했습니다.

  • 음향 특징: B2의 하이라이트–그림자 단면, 상자 크기, 수주로부터의 거리를 로지스틱 회귀에 넣은 모델
  • DINOv2 고정 특징: 범용 영상 기반 모델의 특징을 그대로 쓰고 선형 분류기만 학습
  • DINOv2 미세조정: 마지막 4개 블록까지 학습

세 가지 분할에서 점수를 비교했습니다. 이미지 단위 무작위 분할(복사본 누수 있음), 장면 단위 분할, 연도 분할입니다.

B4

고찰 discussion

한계

  1. CPU만으로 학습해 YOLO는 가장 작은 모델(v8n)을 25에폭 이내로 학습했습니다. 더 큰 모델과 긴 학습으로 수치가 오를 여지가 있습니다.
  2. 레퍼런스 연구의 정확한 분할 방식이 공개되어 있지 않아 수치를 직접 비교할 수 없습니다. 여기서는 "같은 과제·같은 데이터에서 분할에 따라 얼마나 달라지는가"를 보였습니다.
  3. 원본 소나 신호가 아니라 내보내기된 JPEG 영상입니다. 이득 조절, 색상표, 압축 손실이 이미 들어가 있어 신호 수준의 처리는 제한됩니다.
  4. 라벨 없는 유사 물체가 있어, 오경보 수치에는 라벨 누락이 섞여 있습니다.

남은 질문 (종합 고찰로 넘김)

  1. 연도(해역·장비 설정) 사이의 성능 저하를 줄이는 데 무엇이 가장 효과적인가? 영상 정규화, 도메인 적응, 아니면 해역별 소량 라벨?
  2. 하이라이트–그림자 물리 특징과 AI 특징을 결합하면 처음 보는 해역에서 더 견고해지는가?
  3. 원시 신호(챕터 A 같은 정합필터 출력)에 접근할 수 있다면, 영상 이전 단계에서 표적을 더 잘 가를 수 있는가?
  4. 운용 시나리오에서 허용 가능한 화면당 오경보 수는 얼마인가? 이 값이 모델 선택 기준을 바꾼다.
